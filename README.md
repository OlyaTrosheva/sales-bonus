# Проектная работа "Пряники"

Программа на JavaScript для анализа данных о продажах в магазине. Формирует рейтинг продавцов по доходности и рассчитывает бонусы на основе данных выбранного набора.

## Возможности:

- Анализ данных о продажах.

- Расчёт прибыли и бонусов продавцов.

- Формирование рейтинга продавцов по доходности.

- Поддержка нескольких наборов данных.

## Технологии:

- JavaScript (Vanilla JS)

- HTML

### Запуск проекта:

1. Склонируйте репозиторий:

git clone https://github.com/OlyaTrosheva/sales-bonus.git

2. Откройте файл index.html в браузере.

3. Откройте консоль разработчика (DevTools), чтобы увидеть результаты анализа: рейтинг продавцов и рассчитанные бонусы.



### В проекте предусмотрено три примера наборов данных:

- data/dataset_1.js

- data/dataset_2.js

- data/dataset_3.js

### Чтобы выбрать другой набор данных, измените подключаемый файл в index.html:

<script src="data/dataset_1.js"></script>
